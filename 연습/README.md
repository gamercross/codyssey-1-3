# 빈칸 연습 (입학연수 3차 시험 대비)

시험은 빈 화면에서 처음부터 손으로 코드를 쓰고, 돌려 볼 수 있는 것은 파이썬 IDLE뿐이었다. 그래서 이 연습도 같은 꼴로 만들었다. 문제 파일에는 설명만 있고 코드는 한 줄도 없다.

> 문제는 E1-3 미션(MAC · Mini NPU)과 1 · 2주차 내용을 바탕으로 **짐작해서 만든 연습**이다. 실제 시험 문제가 아니다.

## 하는 법 (IDLE)

1. `p1_mac.py`를 IDLE로 연다. 맨 위 설명을 읽고, 그 아래에 함수를 직접 쓴다.
2. 다 쓰면 `check.py`를 열고 **F5**. 문제마다 숨은 케이스를 돌려 점수를 낸다.
3. 틀린 케이스를 보고 고친 뒤 다시 F5. 문제 2~6도 같은 식이다.
4. `글답.md`(문제 7)를 풀고 `풀이/글답_정답.md`와 맞춰 본다.

터미널에서는 `python3 check.py`(모두) · `python3 check.py 1 3`(골라서)로 돌린다.

## 규칙

- **`풀이/` 폴더는 다 쓴 뒤에만 연다.** 미리 보면 손에 남지 않는다.
- 시간을 잰다. 문제 1~6과 글답까지 **120분** 안에.
- import 없이 쓴다. 문제 1은 `sum` · `zip`도 쓰지 않는다. 쓰면 채점기가 `!` 줄로 알려 준다(시험의 사용 제한 코드 연습).
- 문제 파일끼리 import하지 않는다. 시험처럼 파일마다 따로 선다.
- 진짜 시험처럼 하려면 `check.py`의 `SHOW_DETAIL = True`를 `False`로 바꾼다. 그러면 어느 케이스가 틀렸는지 알려 주지 않고 점수만 나온다.
- 함수를 시험해 보려면 파일 맨 아래 `if __name__ == "__main__":` 안에서 한다. 그 밖에 `input()`을 두면 채점기가 멈춘다.

## 문제

| 번호 | 파일 | 만들 것 | 숨은 케이스가 보는 곳 |
|---|---|---|---|
| 1 | `p1_mac.py` | `mac(pattern, filt)` | 빈 입력, 크기 다름, 줄 길이 들쭉날쭉, float |
| 2 | `p2_filters.py` | `make_cross(n)` · `make_x(n)` | 짝수 · 0 · 음수, `[[0]*n]*n` 함정 |
| 3 | `p3_judge.py` | `judge(pattern, cross, x, eps)` | float 동점(`==` 금지), eps 바꾸기 |
| 4 | `p4_label.py` | `normalize(label)` | 앞뒤 공백 · 탭, 대소문자, None · 숫자 |
| 5 | `p5_summary.py` | `summarize(data)` | 숫자 순 정렬, 잘못된 케이스에서 안 멈추기, 미션 `data.json` |
| 6 | `p6_grid.py` | `class Grid` | 복사, 음수 인덱스, `__str__` 꼴 |
| 7 | `글답.md` | Q1~Q10 | MAC · 복잡도 · 부동소수점 · chmod · git · docker |

## 제출 전에 스스로 물을 것

빈칸 문제의 부분 점수는 대개 예시만 맞추고 낸 데서 깎인다. 제출하기 전에 세 가지를 물어본다.

1. 입력이 비어 있으면?
2. 크기 · 꼴이 문제와 다르면?
3. 값이 float이면?
