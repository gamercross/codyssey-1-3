# 문제 7 정답

| 번호 | 정답 | 까닭 |
|---|---|---|
| Q1 | `1` | 두 필터가 겹치는 곳은 가운데 한 칸뿐이다 |
| Q2 | `625` | 칸마다 한 번씩: 25 × 25 |
| Q3 | `False` | 0.1 + 0.2 는 0.30000000000000004 라서 0.3과 다르다. 그래서 `abs(a - b) < eps`로 비교한다 |
| Q4 | `4` | 칸 수가 N²이라 N이 2배면 칸은 4배 |
| Q5 | `O(N^2)` | 모든 칸을 한 번씩 곱하고 더한다 |
| Q6 | `1` | `* 3`은 같은 줄 하나를 세 번 가리키게 만든다. 줄마다 따로 만들려면 `[[0] * 3 for _ in range(3)]` |
| Q7 | `25` | 가로 13 + 세로 13 − 가운데 겹침 1 = 2N − 1 |
| Q8 | `r-x` | 7 = rwx(주인), 5 = r-x(그룹), 4 = r--(나머지) |
| Q9 | `git commit --amend` | `-m "새 메시지"`를 붙이면 편집기 없이 바로 고친다 |
| Q10 | `-p` | 예: `docker run -p 8080:80 이미지` (호스트:컨테이너) |
